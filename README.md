# AI Огляд

**AI Огляд** — навчальний настільний застосунок мовою Java для перегляду технологічних новин із RSS-стрічок. Розроблено в межах курсового проєкту з об’єктно-орієнтованого програмування.

**Авторка:** Аліна Квітка · група КС-24 · Харківський національний університет імені В. Н. Каразіна.

## Можливості

- Завантаження статей із кількох RSS-джерел; ручне та фонове автоматичне оновлення кожні 15 хвилин.
- Пошук за заголовком і описом; фільтрація за категорією, джерелом та датою; сортування.
- Чотири категорії: штучний інтелект, робототехніка, програмування, технології.
- Обране зі збереженням між запусками; кеш раніше отриманих новин.
- Усунення дублікатів за URL та додатковими ознаками.
- Графічний інтерфейс Java Swing з адаптивним розташуванням карток та ефектом Neon Glow.

Інтерфейс українською мовою. Тексти новин зберігаються мовою джерела (переважно англійською). Тематична класифікація автоматична й може потребувати перевірки окремих результатів.

## Вимоги та запуск

Потрібна **Java 17 або новіша** й інтернет для отримання свіжих новин.

macOS / Linux:

```bash
bash run.sh
```

Windows:

```bat
run.bat
```

Або універсальний спосіб:

```bash
java -jar AI-Ogliad.jar
```

За відсутності інтернету можуть відображатися раніше збережені статті. Додаткове встановлення шрифтів для запуску не потрібне: застосунок використовує доступні системні шрифти.

## Структура

- `src/ua/kvitka/ai/` — Java-код застосунку (інтерфейс, RSS, фільтрація, кеш, обране).
- `test/ua/kvitka/ai/` — автоматизовані перевірки компонентів.
- `AI-Ogliad.jar` — зібрана виконувана програма.
- `run.sh`, `run.bat` — сценарії запуску.

## Компіляція з вихідного коду

```bash
mkdir -p build/classes
javac -encoding UTF-8 -d build/classes $(find src -name '*.java')
jar --create --file AI-Ogliad.jar --main-class ua.kvitka.ai.Main -C build/classes .
```

Цей приклад команди розрахований на macOS / Linux; для Windows збирання виконується аналогічно через `javac` та `jar`.

Робота є навчальним прототипом, а не комерційним сервісом. Новини належать їхнім авторам і відкриваються на вебсайтах першоджерел.
